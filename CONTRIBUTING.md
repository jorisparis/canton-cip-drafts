# Contributing

This repository hosts a pre-CIP discussion draft for Canton. The goal is to develop the direction, absorb feedback, and produce a version suitable for submission to [`canton-foundation/cips`](https://github.com/canton-foundation/cips) through the [CIP-0000 process](https://github.com/canton-foundation/cips/blob/main/cip-0000/cip-0000.md).

## How to contribute

**Discussion and feedback.** Open an Issue. Please quote the specific passage you are responding to so threads stay easy to follow.

**Suggested edits.** Open a Pull Request against the CIP draft. For small wording changes, a PR with the proposed diff is fastest. For structural changes, please open an Issue first to discuss the direction.

**Questions about scope.** The draft is explicit about what is inside and outside its scope. Open an Issue if a question is not answered by the current text.

## What this draft is not

* A finalized Canton Improvement Proposal.
* An assignment of a CIP number. Numbers are assigned by CIP editors after the draft is submitted to the [cip-discuss mailing list](https://lists.sync.global/g/cip-discuss/topics) and the [cips repository](https://github.com/canton-foundation/cips).
* A proposal to restrict network access, application deployment, or transaction execution.
* An endorsement or safety certification of any application.
* An official position of the Canton Foundation.
