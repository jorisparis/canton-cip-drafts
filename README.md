# Evidence-Based Featured App Rewards

Pre-CIP discussion draft for a programmable framework that weights Canton Featured App rewards using verifiable, activity-relevant claims.

## Status

This is a pre-CIP discussion draft. It has not been submitted to `canton-foundation/cips` and has not been assigned a CIP number. The purpose of this repository is to develop the direction, absorb feedback via Issues and Pull Requests, and produce a version suitable for submission through the CIP process (see [CIP-0000](https://github.com/canton-foundation/cips/blob/main/cip-0000/cip-0000.md)).
